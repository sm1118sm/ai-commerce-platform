# TextCNN 추천 모델 검증

## 모델

- 입력: 상품명, 카테고리, 설명, 태그, 브랜드, 한국어 쇼핑 의도 210개
- 구조: 문자 임베딩 → 2·3·4·5·6 크기 합성곱 → ReLU → 전역 최대 풀링
- 출력: 100차원 정규화 상품 의미 벡터와 30개 상품 확률
- 배포 모델: `data/textcnn_model.npz` (약 124KB)
- 런타임: NumPy

## 자연어 추천 품질

사람이 승인한 한국어 쇼핑 의도 12개, Top-5 기준 결과다.

| 지표 | 결과 |
| --- | ---: |
| Precision@5 | 0.200 |
| Recall@5 | 0.917 |
| NDCG@5 | 0.863 |
| MRR | 0.878 |

## 추론 속도

같은 회원의 관심사, 최근 행동 2개, 자연어 요청을 포함한 추천을 연속 5회
측정했다.

| 회차 | 시간 |
| --- | ---: |
| 1 | 0.0284초 |
| 2 | 0.0086초 |
| 3 | 0.0096초 |
| 4 | 0.0087초 |
| 5 | 0.0080초 |
| 평균 | **0.0127초** |
| 최대 | **0.0284초** |

모델 최초 로드와 전체 카탈로그 임베딩 생성은 0.0509초였다. 측정 환경에
따라 절대 시간은 달라질 수 있지만, 자동 테스트는 각 추천 추론이 2초를
넘으면 실패하도록 구성했다.

## 회원별 결과 검증

- 전자기기 행동: P001 8점, P002 5점
- 스포츠 행동: P024 8점, P025 5점

두 행동 이력으로 생성한 상위 추천 목록은 서로 달랐고, 각 목록의 첫 두
상품은 해당 사용자가 주로 행동한 카테고리와 일치했다.
