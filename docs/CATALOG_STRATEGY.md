# 2030 타깃 이커머스 상품 카탈로그 전략

## 방향

상품명은 모바일 검색 결과에서 핵심 정보가 먼저 보이도록
`핵심 기능 + 사용 상황 + 상품 유형` 순서로 작성한다. 상품 설명은 확인되지
않은 효능이나 허위 할인을 피하고 실제 추천에 사용할 용도·장소·소재 정보를
포함한다.

2025년 3월 국내 온라인쇼핑에서 모바일 거래 비중은 76.9%였고 의복 거래는
전월 대비 증가했다. 온라인 해외 직접 판매에서는 화장품, 직접 구매에서는
의류·패션, 식품, 생활용품이 주요 상품군이었다.
[통계청 온라인쇼핑동향](https://www.kostat.go.kr/board.es?act=view&bid=241&list_no=436309&mid=a10301010000)

러닝은 2030세대의 헬시플레저와 패션이 결합된 관심 영역으로 확인되어 러닝
재킷, 쿠션 스니커즈, 러닝 벨트의 상품명과 태그를 강화했다.
[네이버 2025 러닝코어 자료](https://navercorp.com/media/pressReleasesDetail?seq=33243)

## 반영한 상품군

- 전자기기: ANC 헤드폰, 웨어러블, 미니빔, 데스크테리어, 멀티 충전
- 패션: 러닝코어·고프코어, 오버핏, 테크 백팩, 데일리 쿠션화
- 홈리빙: 원룸 무드, 재택근무, 모니터 라이트바, 소형 청소
- 뷰티: 피부 장벽 보습, 자외선 차단, 비건 립, 두피 케어
- 스포츠: 홈트, 러닝 수납, 무게 조절 덤벨
- 식품: 저당 단백질 간식, 디카페인 홈카페, 무카페인 허브티

## 데이터 필드

- `name`: 검색 핵심 키워드가 포함된 상품명
- `category`: 탐색과 다양성 제어용 상위 카테고리
- `description`: 사용 상황과 핵심 사양
- `tags`: 검색·임베딩에 사용할 동의어와 용도
- `brand`: 상품 카드와 브랜드 다양성용 가상 데모 브랜드
- `price`, `stock`, `rating`: 랭킹·필터·품절 처리

브랜드는 실제 상표가 아닌 데모용 가상 브랜드다. 실제 서비스로 전환할 때는
공급 계약과 상품 원장을 기준으로 교체해야 한다.

## 품질 규칙

- 상품 ID와 이름은 중복될 수 없다.
- 가격은 0보다 커야 한다.
- 재고는 음수가 될 수 없다.
- 평점은 0~5 범위다.
- 상품명·카테고리·설명·태그·브랜드는 비어 있을 수 없다.
- 품절·비활성 상품은 추천 결과에서 제외한다.
- 실제 근거가 없는 할인율, 의학적 효능, 판매량 문구는 표시하지 않는다.
