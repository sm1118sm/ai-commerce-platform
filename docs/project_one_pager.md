# StylePick AI 일일 운영 리포트 자동화

## 문제

쇼핑몰의 주문·행동·검색·재고 데이터는 MySQL에 저장되지만 운영자가 매일 여러
테이블을 직접 확인해야 한다. 확인 과정이 반복되고 중요한 저재고나 취소 주문을
놓칠 수 있다.

## 가장 작은 목표

전일 데이터 한 묶음을 읽어 핵심 운영 지표와 확인 항목이 담긴 Markdown 보고서
한 개를 자동 생성한다.

## 입력

- 운영: MySQL의 `users`, `behavior_logs`, `user_orders`, `order_items`, `products`
- 검증: `data/daily_report_sample.json`

## 처리

1. 지정 날짜와 전일의 행동·회원·주문 지표를 읽기 전용으로 집계한다.
2. 인기 검색어·판매 상품·저재고와 간이 전환율을 계산한다.
3. 근거가 있는 주의 항목만 골라 일일 보고서와 실행 로그를 남긴다.

## 결과

- 보고서: `reports/daily/{YYYY-MM-DD}.md`
- 로그: `logs/daily_report.log`
- 선택적 전달: 생성된 동일 보고서를 `sm1118sm@gmail.com`으로 이메일 발송

## 실행 조건

기본 실행일은 한국 시간 기준 어제이며, VPS `cron`에서 매일 오전 9시에 실행한다.
이메일은 `--send-email`을 지정하고 Gmail 앱 비밀번호가 있을 때만 발송한다.

## 성공 기준

- 테스트 입력 한 개로 보고서 한 개가 생성된다.
- 종료 상태가 0이고 로그에 `SUCCESS`, 날짜, 결과 경로가 남는다.
- 보고서에 회원·행동·주문·검색·저재고 지표와 해석 제한이 포함된다.
- 운영 테이블을 수정하는 SQL을 실행하지 않는다.

## 제외 범위

- 이메일 이외 메신저 발송
- 주문, 상품, 가격 또는 재고 변경
- 추천 노출 로그가 없는 상태에서 추천 클릭률 추정
- 검색과 주문의 직접 연결 키가 없는 상태에서 검색별 구매 전환 추정
- 실제 결제 및 매출 처리

## 확장 후보

추천 노출 위치와 클릭 이벤트를 추가한 뒤 추천 CTR과 전환을 집계한다.
