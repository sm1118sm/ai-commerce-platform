# StylePick AI 작업 체크리스트

이 문서는 실제 사용자 시연이 가능한 웹사이트를 만드는 순서대로 관리한다.
작업은 기능 브랜치에서 진행하고 테스트가 끝나면 Pull Request로 `main`에
병합한다.

세부 실행 순서와 단계별 완료 조건은
[`NEXT_STEPS_CHECKLIST.md`](NEXT_STEPS_CHECKLIST.md)를 따른다.
