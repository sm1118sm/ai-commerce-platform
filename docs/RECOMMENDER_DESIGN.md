# TextCNN 회원별 추천 모델

## 목표

StylePick AI는 하나의 딥러닝 TextCNN 모델만 사용한다. 상품 의미 특징을
CNN으로 학습하고, 실제 회원별 행동을 서로 다른 사용자 벡터로 결합해 추천
순위를 개인화한다.

## 모델 입력과 학습

각 상품의 다음 필드를 하나의 한국어 문자 시퀀스로 결합한다.

- 상품명
- 카테고리
- 상세 설명
- 검색 태그
- 브랜드

TextCNN은 32차원 문자 임베딩과 크기 2·3·4·5·6의 합성곱 필터를 사용한다.
필터별 ReLU와 전역 최대 풀링 결과를 연결하고 상품 30개를 구분하도록
교차 엔트로피로 학습한다. 카탈로그 문장과 상품별 한국어 쇼핑 의도
210개를 함께 사용한다. 학습 명령은 다음과 같다.

```bash
python scripts/train_textcnn.py
```

학습 결과는 `data/textcnn_model.npz`에 저장된다. 배포 서버는 NumPy만으로
이 파일을 추론하므로 GPU, PyTorch, TensorFlow가 필요하지 않다.

## 회원별 개인화

카탈로그의 모든 상품은 시작 시 한 번 CNN 벡터로 변환된다. 회원의 관심
카테고리, 찜 상품, 자연어 요청과 최근 행동 상품 벡터를 가중 평균해 별도의
취향 벡터를 만든다.

| 행동 | 기본 가중치 |
| --- | ---: |
| 상품 클릭 | 1 |
| 찜 | 4 |
| 장바구니 | 5 |
| 구매 | 8 |

회원 A가 전자기기를 주로 보고 회원 B가 스포츠 상품을 주로 보면 두 사용자의
CNN 취향 벡터가 달라져 상위 추천 상품도 달라진다. 찜·장바구니에서 제거한
상품은 부정 행동 패널티를 적용하며 이미 찜하거나 구매한 상품은 결과에서
제외한다.

## 최종 점수

```text
개인화 점수 =
  CNN 콘텐츠 유사도 × 0.30
  + 관심 카테고리 × 0.20
  + CNN 행동 유사도 × 0.20
  + 예산 적합도 × 0.10
  + 최근 트렌드 × 0.10
  + 평점 × 0.10
  - 부정 행동 패널티
```

행동이 전혀 없는 신규 회원은 CNN 사용자 벡터를 만들 수 없으므로 예산,
인기도, 평점, 최근 트렌드를 이용한 콜드 스타트 순위를 제공한다. 행동이
쌓이는 즉시 CNN 개인화 모드로 전환된다.

## 성능 원칙

- 학습은 오프라인에서만 실행한다.
- 웹 요청에서는 약 124KB 모델과 NumPy 추론만 사용한다.
- 카탈로그 CNN 벡터는 Streamlit 리소스 캐시에 보관한다.
- 알려진 관심사와 행동은 캐시된 상품 벡터를 재사용한다.
- 자연어 요청이 있을 때만 문장을 CNN으로 한 번 추가 인코딩한다.

자동 테스트는 서로 다른 행동 이력을 가진 두 사용자의 상위 결과가 실제로
달라지는지와 5회 추천 추론이 각각 2초 이내인지 검증한다.
