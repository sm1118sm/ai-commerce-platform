# StylePick AI 추천 모델 설계

## 1. 결론

1차 모델은 **multilingual-e5-small 의미 임베딩 기반의 설명 가능한 하이브리드
추천 시스템**으로 운영한다. 현재 상품이 30개이고 사용자 행동 데이터가
적기 때문에 순수 협업 필터링은 사용하지 않는다. 사용자와 행동 데이터가
충분히 쌓이면 현재 모델의 점수에 협업 필터링 점수를 추가한다.

## 2. 추천 목표

- 처음 가입한 사용자에게도 즉시 유효한 상품을 보여준다.
- 관심사와 실제 행동이 달라지면 추천 결과도 달라진다.
- 품절, 찜한 상품, 이미 구매한 상품은 반복 추천하지 않는다.
- 한 카테고리만 과도하게 노출하지 않는다.
- 각 추천에 사용자가 이해할 수 있는 이유를 표시한다.

## 3. 1단계 모델 — 현재 데이터에 적합

### 콘텐츠 모델

상품명, 카테고리, 설명, 태그, 브랜드를 하나의 문서로 만들고 다국어 E5
임베딩으로 벡터화한다. 사용자가 입력한 자연어 의도와 관심사, 찜·행동
상품도 같은 공간의 사용자 벡터로 만든 뒤 코사인 유사도를 계산한다.

E5를 기본 모델로 선정한 이유:

- 한국어에서 단어가 정확히 같지 않아도 문장의 의미를 비교한다.
- 별도 API 비용과 외부 전송이 없다.
- 상품과 사용자가 적은 콜드 스타트 상황에서도 동작한다.
- 고정 벤치마크에서 TF-IDF보다 NDCG@5가 약 3.2배 높았다.

상품 데이터에는 앞으로 `brand`, `tags`, `color`, `use_case` 필드를 추가한다.
카테고리를 두 번 넣어 카테고리 단어의 중요도를 높이는 현재 방식은 유지하되,
실제 상품 데이터가 늘면 필드별 가중치로 교체한다.

### 행동 모델

| 행동 | 기본 점수 | 의미 |
|---|---:|---|
| 상품 조회 | 1 | 약한 관심 |
| 검색 | 1 | 탐색 의도 |
| 찜 추가 | 4 | 명시적 관심 |
| 찜 해제 | -3 | 관심 감소 |
| 장바구니 추가 | 5 | 강한 구매 의도 |
| 장바구니 제거 | -2 | 구매 의도 감소 |
| 구매 | 8 | 가장 강한 선호 |

최근성 가중치:

- 1일 이내: 1.0
- 7일 이내: 0.8
- 30일 이내: 0.5
- 90일 이내: 0.2

같은 상품의 행동 점수를 합산한 뒤 긍정 행동 상품의 텍스트로 사용자 행동
벡터를 만든다. 부정 행동은 해당 상품의 최종 점수를 낮추는 데 사용한다.

### 개인화 점수

```text
최종 점수 =
  콘텐츠 유사도 0.30
  + 관심 카테고리 0.20
  + 최근 행동 유사도 0.20
  + 예산 적합도 0.10
  + 최근 트렌드 0.10
  + 상품 평점 0.10
  - 부정 행동 패널티
```

하드 필터:

- 재고가 0인 상품 제외
- 이미 찜한 상품 제외
- 이미 구매한 상품 제외

재정렬:

- 한 카테고리는 추천 결과의 최대 절반까지만 허용
- 점수가 비슷하면 인기도와 평점이 높은 상품 우선

### 신규 사용자 추천

행동이 없는 사용자는 다음 점수로 추천한다.

```text
콜드 스타트 점수 =
  예산 적합도 0.25
  + 최근 트렌드 0.35
  + 인기도 0.25
  + 평점 0.15
```

관심 카테고리도 선택하지 않았다면 예산·트렌드·인기도·평점만 사용하며,
화면에 `콜드 스타트 추천`이라고 표시한다.

## 4. 2단계 모델 — 행동 데이터가 쌓인 뒤

사용자-상품 상호작용이 충분해지면 암시적 피드백 협업 필터링을 추가한다.

도입 판단 기준:

- 실제 사용자 100명 이상
- 행동 로그 5,000건 이상
- 상품당 상호작용과 사용자당 상호작용이 각각 여러 건 존재

후보 모델:

1. LightFM 또는 유사한 하이브리드 행렬 분해
2. implicit ALS
3. 데이터가 훨씬 커진 뒤에만 신경망 기반 추천 검토

2단계 최종 점수는 `현재 하이브리드 점수 0.6 + 협업 필터링 점수 0.4`에서
시작해 오프라인 평가로 비율을 조정한다. 신규 상품과 신규 사용자는 계속
1단계 콘텐츠 모델이 담당한다.

## 5. 반드시 저장할 데이터

- 추천 노출: 사용자, 상품, 노출 순위, 모델 버전, 시각
- 추천 클릭: 추천 영역에서 클릭했는지 여부
- 찜, 장바구니, 구매 전환
- 당시 최종 점수와 추천 이유

비밀번호, 전화번호 등 추천에 필요 없는 개인정보는 모델 데이터에 넣지 않는다.

## 6. 평가 방법

오프라인:

- Precision@K, Recall@K, NDCG@K
- 카테고리 다양성
- 품절·구매 완료 상품 노출률
- 인기순 추천 대비 개선 정도

온라인 시연:

- 추천 클릭률
- 찜 전환율
- 장바구니 전환율
- 모의 주문 전환율

평가 시 과거 행동으로 사용자 프로필을 만들고 가장 최근 행동을 정답으로
분리한다. 모델 가중치와 결과에는 항상 모델 버전을 함께 기록한다.
