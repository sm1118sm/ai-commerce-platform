# StylePick AI 발표 원고

## 1. 표지

**StylePick AI — 추천 이유를 알려주는 개인화 이커머스**

관심 카테고리와 실제 행동 로그로 회원마다 달라지는 3일 해커톤 MVP입니다.

## 2. 문제 정의

- 작은 쇼핑몰은 모든 사용자에게 같은 상품을 노출합니다.
- 구매 이력이 없는 신규 사용자는 개인화하기 어렵습니다.
- 근거가 없는 추천은 사용자가 신뢰하기 어렵습니다.

## 3. 해결 방법

사용자가 닉네임, 관심 카테고리, 예산을 설정하고 상품을 찜하면 상품명,
카테고리, 설명을 AI가 분석해 관련 상품과 추천 이유를 제공합니다.

## 4. 사용자 흐름

```text
회원가입 → 취향 설정 → 상품 탐색·행동 수집 → AI 추천 → 장바구니 → 모의 주문
```

실제 결제만 제외하고 회원가입·로그인과 회원별 데이터 분리를 구현했습니다.

## 5. 기술 구조

```text
products.csv → MySQL 상품·재고
   ├─ pandas → 상품 검색·필터
   └─ TF-IDF → 상품 벡터
                   ↑
관심 카테고리 + 최근 행동 + 찜·구매 → 사용자 벡터
                   ↓
          코사인 유사도 + 규칙 점수
                   ↓
          Streamlit 추천 화면
```

Python 단일 앱으로 구성해 로컬 시연 안정성을 높였습니다.

## 6. AI 추천 알고리즘

TF-IDF가 30개 상품의 어휘와 중요도를 학습합니다. 사용자 취향과 상품을
같은 벡터 공간에 표현하고 코사인 유사도를 계산합니다.

```text
개인화 점수 =
콘텐츠 35% + 카테고리 20% + 최근 행동 20% + 예산 10% + 트렌드 15%
```

TF-IDF와 유사도는 AI/ML 영역이며 나머지는 설명 가능한 비즈니스 규칙입니다.

## 7. 콜드 스타트와 설명 가능성

사용자 데이터가 없으면 트렌드·예산·누적 인기도·평점으로 추천합니다.
취향 정보가 생기면 즉시 개인화 점수로 전환합니다.

추천 카드에는 다음 근거를 표시합니다.

- 관심 카테고리와 일치
- 찜 상품과 텍스트가 유사
- 예산 범위에 포함

## 8. 라이브 데모

1. 전자기기·스포츠와 예산을 저장합니다.
2. 스마트 워치 또는 요가 매트를 찜합니다.
3. 추천 탭에서 결과와 근거를 확인합니다.
4. 추천 상품을 장바구니에 담습니다.
5. 수량 변경 후 모의 주문을 완료합니다.

## 9. 검증 결과

- 30개 상품 ID와 데이터 구조 검증
- 관심 카테고리가 추천 상단에 반영되는지 검증
- 찜 상품 제외와 유사성 이유 검증
- 콜드 스타트와 점수 범위 검증
- 네 개 화면과 모의 주문 통합 검증
- 자동 테스트 10개 통과
- 실제 Streamlit 서버 health check 통과

## 10. 한계와 향후 발전

현재는 다중 회원, 행동 로그, 상품 재고와 주문을 MySQL 8로 처리합니다.
다음 단계에서는 실제 로그 기반 가중치 학습, 문장 임베딩 비교, A/B 테스트를
추가할 수 있습니다.

3일 동안 기능 수를 늘리기보다 **실제로 작동하고 설명할 수 있는 추천 구매
흐름**을 완성하는 데 집중했습니다.
